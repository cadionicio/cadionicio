## 🚀 Proyectos destacados

### [LeadLaunch](https://github.com/cadionicio/LeadLaunch) — copiloto de ventas para emprendimientos de comida
Analiza las reseñas negativas de la competencia cercana, genera campañas con IA (Gemini) y arma cotizaciones exactas que se envían por WhatsApp en un toque.
`Kotlin` `Jetpack Compose` `FastAPI` `PostgreSQL` `Gemini API` · API desplegada en Render + Neon · **v0.5.1 en producción**

### [BodegaControl](https://github.com/cadionicio/bodegacontrol) — ventas e inventario de una bodega desde el celular
Ventas sin duplicados (idempotencia), stock que siempre cuadra (transacciones), roles propietario/cajero, pagos con Yape/Plin y reportes en PDF/CSV.
`React` `Capacitor` `FastAPI` `PostgreSQL` `Docker` · [API en vivo](https://bodegacontrol.vercel.app/docs)

### [SCRAPPER_MEDIA](https://github.com/cadionicio/SCRAPPER_MEDIA) — extracción de datos de redes sociales a Excel
Un solo comando para sacar anuncios y publicaciones de Facebook, TikTok y X, sin duplicados y organizados en Excel.
`Python` `Apify` `pandas`

### [Sistemas Analíticos](https://github.com/cadionicio/Sistemas-Analiticos) — 8 sistemas de analítica para gestión empresarial
Inventarios, costeo, distribución, mantenimiento y atención al cliente, con analítica descriptiva, diagnóstica, predictiva y prescriptiva.
`TypeScript` `Análisis de datos`

### [Filtros y reconocimiento MNIST](https://github.com/cadionicio/filtros-y-reconocimiento-mnist) — visión por computadora y machine learning
Banco de filtros Leung-Malik sobre imágenes y comparación de kNN, Regresión Logística y SVM para reconocer dígitos.
`Python` `scikit-learn` `Jupyter`
